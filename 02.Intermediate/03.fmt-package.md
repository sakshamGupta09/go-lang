# Fmt package

- **Printing** → Display some information on stdout.
- **Scanning** → read input from console where user is typing.
- **Creating Formatted Strings** → Nothing is printed. Instead, the formatted result is stored in a variable.
- **Formatted error** → Create formatted errors.



## Printing functions

## Print

- No spaces added if we print multiple values.
- No newline at the end. Cursor stays at same line.
- Concatenates values.

```go
func main() {
	fmt.Print("hello", "world", 5) // helloworld5 10%        
}
```

## Println

- Adds spaces between them for better readability.
- After printing, Takes the cursor to new line.

```go
func main() {
	fmt.Println("hello", "world", 5) // hello world 5
}
```


## Printf

- Create a string with placeholders and replace those placeholders with  variable values.
- Does NOT add newline automatically.

```go
name := "Saksham"
age := 28
fmt.Printf("Name: %s, Age: %d\n", name, age)

```


## Formatting functions

- Instead of printing the output on stdout, Give me the output.
- They can be used for string concatenation purpose as well.
- `Sprint`, `Sprintf`, `Sprintln`.


## Scanning functions

- Take input from the user through console and store in variables.
- Whenever scan function is encountered, the program waits till it receives the inputs.
- We must pass pointers (&var) so they can modify the variables as everything in Go is passed by value by default.

## Scan

- Scan function takes addresses of variables. It can take 0 to n parameters.
- When entering values in the console, values should be seperated by a `space` or a `enter`.
- The input values are validated against their types and default value is assigned if value of wrong type is provided.

```go
func main() {
	var name string
	var age int8

	fmt.Println("Enter name and age")

	fmt.Scan(&name, &age)

	fmt.Println(name, age)
}
```

## Scanln

- Stops reading input from the console when a newline is encountered.

## Scanf

- Expects the input in the exact same format as we declare in the bouble quotes.

```go
	fmt.Scanf("%s %d", &name, &age)
```

## Errorf

- Creates and returns a new error object.
- This is better than `errors.New()` which takes only string values.


```go
func main() {
	log := fmt.Errorf("%s %d", "John", 33)
}
```

## Error Wrapping

- Adding more context to an error while still keeping the original error.

```go
func readFile() error {
    _, err := os.Open("data.txt")
    if err != nil {
        return fmt.Errorf("readFile failed: %w", err)
    }
    return nil
}
```
```go
readFile failed: open data.txt: no such file or directory
```
You added context: Where it failed , But preserved original error, That’s error wrapping.
