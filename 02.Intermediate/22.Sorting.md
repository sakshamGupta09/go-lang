# Sorting

- I have a collection of things and I want to rearrange them based on a rule.
- Modifies the original slice. Doesn't return a new copy.
- By default sorts in ascending order.


## slices.sort

```go
func task() {
	nums := []int{4, 1, 5, 3, 2}

	slices.Sort(nums)
	fmt.Println(nums)
}
```

## Create a new sorted collection

```go
func task() {
	original := []int{5, 2, 8, 1}

	sorted := slices.Clone(original)

	slices.Sort(sorted)

	fmt.Println(original)
	fmt.Println(sorted)
}
```

## Stable vs Unstable Sort

- Order for equal items should remain as per the original array or not.
- `sort.Slice` is not stable sort.
- `sort.SliceStable` is stable .
