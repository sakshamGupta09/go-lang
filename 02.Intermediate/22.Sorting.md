# Sorting

- I have a collection of things and I want to rearrange them based on a rule.
- Modifies the original slice. Doesn't return a new copy.
- By default sorts in ascending order.


## slices.sort

```go
func task() {
	nums := []int{4, 1, 5, 3, 2}

	slices.Sort(nums)
	fmt.Println(nums)
}
```

## Create a new sorted collection

```go
func task() {
	original := []int{5, 2, 8, 1}

	sorted := slices.Clone(original)

	slices.Sort(sorted)

	fmt.Println(original)
	fmt.Println(sorted)
}
```

## slices.SortFunc

- I want to sort based on a custom rule.

```go
negative → a should come before b
zero     → equal
positive → a should come after b
```

```go
nums := []int{5, 2, 8, 1, 3}

slices.SortFunc(nums, func(a, b int) int {
	return b - a
})

fmt.Println(nums)
```

## Sorting structs

```go
slices.SortFunc(people, func(a, b Person) int {
	return a.Age - b.Age
})
```

## Binary Search

```go
slices.Sort(nums)

index, found := slices.BinarySearch(nums, 3)

fmt.Println(index, found)
```
