# String functions

## String builder

## Problem

- In Go, strings are immutable. That means every time you do:

```go
s = s + "world"
```
- Creates a new string
- Copies old data
- Adds the new part
- Discards the old string
- If this happens inside a loop, you create many temporary strings and copying large texts, causing memory and performance issues.


## Solution

- Build strings incrementally in a memory efficient way for better performance.
- Because it does not creates temporary strings and we do not have to copy strings.
- `strings.Builder` is a type.
- It's like a typewriter. You keep writing stuff to this builder using `builder.WriteString` or `builder.WriteRune` and when we are done typing, we can compile everything and get output string using `builder.String`.

```go
func main() {
	var builder strings.Builder

	builder.WriteString("Hello")
	builder.WriteString(", ")
	builder.WriteString("World")

	result := builder.String()

	fmt.Println(result) // Hello, World
}
```

- If we are done with one string and want another, instead of creating another new builder we can reset this and resuse.

```go
func main() {
	var builder strings.Builder

	builder.WriteString("Hello")
	builder.WriteString(", ")
	builder.WriteString("World")

	result := builder.String()

	fmt.Println(result) // Hello, World

	builder.Reset()

	builder.WriteString("STARTING A FRESH WORD")

	result = builder.String()

	fmt.Println(result) // STARTING A FRESH WORD
}

```
