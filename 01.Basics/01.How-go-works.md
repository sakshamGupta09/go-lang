# How Go works

```go
package main

import "fmt"

func main() { fmt.Println("Hello World") }

```
- Let’s understand how this Go program actually runs, step by step -

## 1️⃣ Compilation (go build or go run)

A Program is a set of instructions to a computer. But computers only understand machine language not our Go source code. So, we need to convert our source code to machine code so that machines can execute it.


- Parses the code → checks syntax.
- Type checks → ensures types are correct.
- The source code gets compiled into machine code for the target operating system/architecture.

## 2️⃣ Program Execution

- The executable contains compiled machine instructions.
- The OS loads it into memory.
- Then the Go runtime initializes some things before your `main()` actually executes.

```GO
OS
 │
 ▼
Go executable
 │
 ▼
Go runtime initialization
 │
 ▼
main()
 │
 ▼
fmt.Println()
 │
 ▼
"Hello, World!"
```


## Go Runtime

Go programs aren't literally just your code. A compiled Go executable also contains/supports the Go runtime, which handles things such as:

- Goroutines
- Scheduling
- Garbage collection
- Memory management
- Timers
- Interaction with the OS


## package main

- Every Go source file belongs to a package.
- Normally packages are imported by other code, but `main` package is special.
- `package main` tells Go "this package is an executable program, and execution begins at `func main()`.


## func main

- When you execute a Go executable, execution starts from main().
