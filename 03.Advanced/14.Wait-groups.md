# WaitGroup

- We create 10 goroutines from `main` function.
- If main function finishes, all goroutines gets killed. So, we need a way to wait till all the goroutines finish their execution.


## How it works

- Let's have a shared variable counter which indicates count of active goroutines.
- For every new goroutine created, we increment the counter and once the goroutine completes, decrement the shared counter.
- Main will keep waiting till count reaches 0.

## Operations

- A waitGroup has three operations.
- `Add(n)` Add a number n to the shared counter. Add is called before we start a goroutine.
- `Done()` A goroutine completed execution. Please decrease the counter by one.
- `Wait()` Block until counter becomes 0 which means all goroutines have completed.



## Basic Example

```go
func main() {
	var wg sync.WaitGroup

	for i := range 5 {
		wg.Go(
			func() {
				fmt.Println("GOROUTINE NUMBER", i)
				time.Sleep(time.Second)
				fmt.Println("GOROUTINE NUMBER", i, "COMPLETED")
			},
		)

	}

	fmt.Println("Waiting for workers to complete")
	wg.Wait()
	fmt.Println("All workers complete")
}
```

## Parallel API calls


```go
func main() {
	var wg sync.WaitGroup

	for range 3 {
		wg.Go(fetchData)
	}

	fmt.Println("Waiting for workers to complete")
	wg.Wait()
	fmt.Println("All workers complete")
}

func fetchData() {
	fmt.Println("Stared fetching data.....")
	time.Sleep(time.Second * 2)
	fmt.Println("Data fetch completed")
}
```

## With Results channel

```go
func worker(id int, results chan<- int, wg *sync.WaitGroup) {
	defer wg.Done()

	fmt.Printf("Worker %d started working ...\n", id)
	time.Sleep(time.Second * 2)
	fmt.Printf("Worker %d completed work ...\n", id)
	results <- id * 2
}

func main() {
	var wg sync.WaitGroup
	numJobs := 3
	numWokers := 3

	results := make(chan int, numJobs)

	wg.Add(numJobs)

	for i := range numWokers {
		go worker(i, results, &wg)
	}

	go func() {
		wg.Wait()
		close(results)
	}()

	for result := range results {
		fmt.Println(result)
	}

}
```

## Construction Woker example

```go
type Worker struct {
	id   int
	task string
}

func (w *Worker) worker(wg *sync.WaitGroup) {
	defer wg.Done()

	fmt.Printf("Worker %d started working on %s ...\n", w.id, w.task)
	time.Sleep(time.Second * 2)
	fmt.Printf("Worker %d completed task %s ...\n", w.id, w.task)
}

func main() {
	var wg sync.WaitGroup

	tasks := []string{"Task 1", "Task 2", "Task 3", "Task 4", "Task 5"}

	for i, task := range tasks {
		worker := Worker{id: i + 1, task: task}
		wg.Add(1)
		go worker.worker(&wg)
	}

	wg.Wait()
	fmt.Println("All goroutines completed")
}
```
